# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, be constructive, assume good intent, and keep discussion
about the work. Harassment, personal attacks and discriminatory language are
not tolerated.

Reports can be sent to thalhaahamedt@gmail.com. They are handled privately.
